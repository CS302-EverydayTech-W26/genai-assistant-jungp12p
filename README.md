# GenAI Partner

## Intructions for Use

1. Run the application in your terminal:
   ```
   python web_assistant.py
   ```

2. Open the web interface in your browser and start entering prompts in the text box.

3. Wait a couple of seconds for the response to generate.

4. Enter a new prompt and repeat!

Enjoy chatting with your AI assistant!
